## 📖 About

**Komorebi** (木漏れ日 - sunlight filtering through leaves) is an intelligent Japanese learning application powered by **Google's Gemini AI**. Whether you're a complete beginner or an intermediate learner, Komorebi provides personalized lessons, interactive exercises, and real-time feedback to accelerate your Japanese learning journey.

### Why Komorebi?
- 🤖 **AI-Powered Learning** - Personalized lessons using Google Gemini
- ⚡ **Real-time Assistance** - Get instant feedback on your progress
- 🎯 **Beginner Friendly** - Start from scratch with guided lessons
- 🌐 **Fully Deployed** - Access anytime, anywhere at [komoreebi.onrender.com](https://komoreebi.onrender.com)

---

## ✨ Features

- 📝 **Interactive Lessons** - Learn hiragana, katakana, kanji, and vocabulary
- 🎤 **AI Tutor** - Ask questions and get instant explanations in Japanese
- ✅ **Practice Exercises** - Test your knowledge with interactive quizzes
- 💾 **Progress Tracking** - Monitor your learning journey (coming soon)
- 🌙 **Dark Mode Support** - Comfortable learning at any time
- 📱 **Mobile Responsive** - Learn on any device
